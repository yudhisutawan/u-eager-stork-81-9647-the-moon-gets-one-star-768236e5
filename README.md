# The Moon Gets One Star

A one-star review of the Moon, in 120 characters or fewer:

> ★☆☆☆☆ Ghosts me for two weeks every month, then shows up full and acts like nothing happened.

93 characters. The Moon's phases reframed as a flaky ex: it ghosts you for two
weeks, then shows up full and acts like nothing happened. The "shows up full"
pun only works for the Moon.

## How it runs

`main.py` is stdlib-only and writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` by default). Same bytes on every run:

```sh
python3 -S -P main.py
```
